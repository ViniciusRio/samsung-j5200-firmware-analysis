# Compatibilidade

O firmware original não foi modificado. Assim, áudio, vídeo, HDMI, USB, Wi-Fi, controle remoto, atualização e recuperação não sofreram alterações por este projeto. A interface experimental roda apenas em navegador de computador; a compatibilidade com o navegador da TV, a API do controle e o SDK legado **não foi validada**. Mesmo em caso de adaptação futura, um aplicativo legado não substitui automaticamente Smart Hub ou o menu nativo.

A [Samsung classifica J5200 como Legacy Platform / TV SDK 5.1](https://developer.samsung.com/smarttv/develop/specifications/tv-model-groups.html). A [FAQ legada](https://developer.samsung.com/smarttv/legacy/samsung-legacy-platform-faq.html) afirma que Tizen Studio não cria pacote legado e documenta o SDK apropriado. Os formatos e APIs específicos do SDK devem ser verificados nele antes de empacotar.
